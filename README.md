# Codex of Azeroth

---

## English

If you've ever been questing through Azeroth and wondered *"Wait, who is this person again? Why is this place important?"* — this addon is for you.

Codex of Azeroth is an in-game lore compendium. Think of it as a little encyclopedia that lives inside World of Warcraft. Browse characters, places, factions, events, and concepts. Search for anything. Read the full story. All without alt-tabbing out of the game.

No websites, no wikis, no distractions. Just the lore, right there in your UI.

### What you can do

- **Browse the lore** — over 46 entries across 5 categories: characters, locations, factions, events, and concepts.
- **Search intelligently** — type a name, even misspell it. The fuzzy search will still find what you're looking for.
- **See NPCs in 3D** — select a character and rotate their model with your mouse. See Thrall, Jaina, Arthas, and more up close.
- **Explore the timeline** — from the War of the Ancients to The War Within, follow Azeroth's history from beginning to... well, the present.
- **Switch between tabs** — each entry has lore, related entries, and sources. Jump between them with a click.

### How to install

1. Copy the `CodexOfAzeroth` folder into `World of Warcraft/_retail_/Interface/AddOns/`.
2. Restart the game, or type `/reload` in chat.
3. Type `/coa` and start exploring.

### Commands

| Command | What it does |
|---------|-------------|
| `/coa` | Opens or closes the main window |
| `/coa search` | Opens the window and puts your cursor in the search bar |
| `/coa thrall` | Opens the entry for Thrall directly (works with any entry id) |
| `/coa help` | Shows available commands |
| `/coa version` | Shows the current version |

### What's inside

- **46+ lore entries** spanning 5 categories, all packed into the addon — no internet required.
- **A complete timeline** from the ordering of Azeroth by the Titans all the way to the underground crisis of The War Within.
- **15 NPCs with 3D models** — all major characters have their in-game model attached so you can see them as they appear in the world.
- **Full bilingual support** — the addon detects whether your game is in English or Spanish and shows the right language automatically.

### What's next

This is a growing project. Here's what I'd love to add in future versions:

- **Favorites** — save your most-read entries for quick access.
- **Personal notes** — write your own thoughts on each entry.
- **More entries** — the goal is 200+ entries covering every major character, place, and event in Warcraft lore.
- **Game tooltips** — hover over NPCs in the world and see a lore summary.
- **World map pins** — see locations from the codex marked on your map.
- **An interactive visual timeline** — scroll through history with style.

### Want to help?

If you know Warcraft lore and want to contribute entries, it's simple. Each entry is just a block of text in a Lua file. Open any file in the `Data/` folder and follow the existing format. Every contribution is welcome.

**Compatibility:** World of Warcraft Retail (The War Within / Midnight, interface 11.0+ / 12.0+).
